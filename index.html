НАСТРОЙКИ

Подключение к ИИ

Сайт работает с шаблонами и без сервера. Для генерации по описанию нужен backend с OpenAI API.

Оставьте поле пустым, если открываете сайт через собственный Node.js сервер. Для GitHub Pages укажите HTTPS-адрес backend на Render.

Никогда не вставляйте API-ключ в браузер или исходный код. Он должен храниться в переменных окружения сервера.
КАК ПОЛЬЗОВАТЬСЯ

От идеи до сайта

  1. Опишите сайт или выберите готовый шаблон.
  2. Посмотрите результат на компьютере, планшете или телефоне.
  3. Попросите ИИ изменить дизайн или откройте вкладку HTML-код.
  4. Скачайте HTML или ZIP и разместите полученный сайт на хостинге.

Без подключения к ИИ доступны шаблоны, редактор, предпросмотр и экспорт. История проектов хранится только в этом браузере.
