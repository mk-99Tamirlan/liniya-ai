Настройки и помощь

«ЛИНИЯ» работает без регистрации. Диалоги сохраняются только в этом браузере. Если очистить данные сайта, история исчезнет.

Режим работы

Демо-режим показывает возможности интерфейса без настоящей нейросети. ИИ через сервер отправляет запросы на ваш собственный backend, где ключ хранится вне браузера.

Оставьте пустым при запуске через локальный сервер проекта. Публичный сервер без ограничений опасен: любой посетитель сможет расходовать ваш баланс API.
