ЛИНИЯ — подключение настоящего ИИ

ВАЖНО: старый API-ключ был отправлен в чат. Отзовите его и создайте новый:
https://platform.openai.com/api-keys
Не добавляйте ключ в GitHub, HTML, JavaScript и ZIP.

ВАРИАНТ 1. Запуск на своём компьютере (Windows PowerShell)
1. Распакуйте архив и откройте папку в VS Code.
2. Установите Node.js 20+.
3. В терминале PowerShell выполните:
   $env:OPENAI_API_KEY = Read-Host 'Вставьте НОВЫЙ API-ключ'
   npm start
4. Откройте http://127.0.0.1:8787
5. В верхнем меню выберите «ИИ через сервер», если не выбралось автоматически.
6. Для проверки откройте http://127.0.0.1:8787/api/health
   Если aiConfigured=true, сервер видит ключ. Это не гарантирует наличие средств на API.

ВАРИАНТ 2. Сайт с настоящим ИИ в интернете (Render)
1. Загрузите обновлённые файлы в свой репозиторий GitHub (без секретов).
2. Откройте https://dashboard.render.com/ и создайте New > Web Service.
3. Подключите репозиторий liniya-ai, ветку main.
4. Language: Node; Build Command: npm install --omit=dev; Start Command: npm start.
5. В Environment добавьте OPENAI_API_KEY = НОВЫЙ ключ (только в панели Render).
6. Также добавьте HOST = 0.0.0.0 и OPENAI_MODEL = gpt-4o-mini.
7. Если используете GitHub Pages, добавьте ALLOWED_ORIGINS:
   https://mk-99Tamirlan.github.io,https://aibekmusabek3-del.github.io
8. Нажмите Deploy. Render выдаст HTTPS-ссылку вида https://...onrender.com.
9. Откройте эту ссылку. Интерфейс и ИИ работают вместе, регистрация не нужна.
10. Если хотите оставить сайт на GitHub Pages, откройте его настройки, вставьте HTTPS-адрес Render в «Адрес сервера», выберите «ИИ через сервер» и сохраните.

ЗАЩИТА И РАСХОДЫ
OpenAI API оплачивается отдельно от ChatGPT Plus. Установите лимиты расходов
для проекта в панели OpenAI. Встроенные ограничения запросов в сервере
предназначены для демонстрации и сбрасываются при перезапуске процесса.
Общедоступный сайт без регистрации и отдельной защиты может расходовать ваш баланс.
