# ЛИНИЯ Studio

**ЛИНИЯ Studio — ИИ-конструктор веб-сайтов.** Пользователь описывает будущий сайт обычными словами, нейросеть генерирует полноценный HTML-документ, а пользователь может редактировать его, видеть результат и скачивать готовый сайт. Регистрация не нужна.

Это новая версия проекта «ЛИНИЯ»: вместо обычного ИИ-чата теперь полноценный конструктор сайтов.

## Возможности

- Генерация сайта по текстовому описанию через OpenAI API.
- Изменение готового сайта новым запросом: «добавь отзывы», «сделай тёмный фон», «поменяй кнопки».
- Три готовых шаблона без подключения к интернету: кофейня, портфолио, цветочный магазин.
- Просмотр на экранах компьютера, планшета и телефона.
- Редактор HTML, CSS и JavaScript в одном файле, применение изменений.
- Отмена предыдущего изменения, история запросов.
- Сохранение до 20 проектов в localStorage браузера, переименование и удаление.
- Экспорт в отдельный `.html` или готовый `.zip` с `index.html` и `README.txt`.
- Адаптивный интерфейс, без регистрации и базы данных.
- Серверный API-ключ, ограничения числа запросов, CORS и ограничение размера ввода.

## Как быстро запустить на Windows в VS Code

Нужен **Node.js 20 или новее**.

1. Распакуйте архив, откройте папку `LINIYA_Constructor` в VS Code.
2. Откройте терминал PowerShell и выполните:

```powershell
npm start
```

3. Откройте http://127.0.0.1:8787

**Без ключа** доступны шаблоны, редактор, предпросмотр, история и скачивание сайтов. Для генерации по описанию нужен ключ API.

## Как включить настоящий ИИ

**Важное предупреждение:** ранее опубликованный в переписке API-ключ нужно отозвать и создать новый. Не вставляйте ключ в HTML, JS, README или GitHub. API OpenAI оплачивается отдельно от подписки ChatGPT.

В новом окне PowerShell, в папке проекта:

```powershell
$env:OPENAI_API_KEY = Read-Host "Новый API-ключ OpenAI"
$env:OPENAI_MODEL = "gpt-4o-mini"
npm start
```

Откройте http://127.0.0.1:8787. Вверху появится «ИИ подключён». Создайте сайт по описанию.

Если ключ неверный, закончилась квота или нет доступа к модели, сервер вернёт понятную ошибку. Сам факт сообщения «ключ задан» в терминале **не означает**, что API успешно ответил.

## Как заменить старый сайт в существующем репозитории GitHub

Ваш репозиторий: https://github.com/aibekmusabek3-del/liniya-ai

Если ранее клонированная папка `LINIYA_GitHub` ещё существует в `Downloads`, распакуйте новый ZIP и выполните в PowerShell:

```powershell
Copy-Item "$HOME\Downloads\LINIYA_Constructor\*" "$HOME\Downloads\LINIYA_GitHub\" -Recurse -Force
Copy-Item "$HOME\Downloads\LINIYA_Constructor\.gitignore" "$HOME\Downloads\LINIYA_GitHub\.gitignore" -Force
Copy-Item "$HOME\Downloads\LINIYA_Constructor\.env.example" "$HOME\Downloads\LINIYA_GitHub\.env.example" -Force
cd "$HOME\Downloads\LINIYA_GitHub"
git status
git add .
git commit -m "Replace AI chat with AI website builder"
git push origin main
```

Если папки `LINIYA_GitHub` нет, сначала выполните:

```powershell
cd "$HOME\Downloads"
git clone https://github.com/aibekmusabek3-del/liniya-ai.git LINIYA_GitHub
```

Затем выполните команды копирования и отправки выше.

**Никогда не добавляйте `.env` с настоящим ключом.** В архиве есть только `.env.example`, без секретов. После `git push` обновится исходный код, но GitHub сам по себе не запустит Node.js.

## Как опубликовать конструктор в интернете

### Способ A. Render — конструктор и ИИ по одному адресу (рекомендуется)

1. Откройте https://dashboard.render.com и войдите через GitHub.
2. Нажмите **New → Web Service**.
3. Подключите репозиторий `aibekmusabek3-del/liniya-ai`, ветка `main`.
4. Установите **Runtime: Node**, **Build Command: `npm install --omit=dev`**, **Start Command: `npm start`**.
5. В **Environment** добавьте:

| Name | Value |
| --- | --- |
| `OPENAI_API_KEY` | новый ключ (секрет, не публиковать) |
| `OPENAI_MODEL` | `gpt-4o-mini` |
| `HOST` | `0.0.0.0` |
| `MAX_DAILY_REQUESTS` | `50` |
| `MAX_DAILY_PER_IP` | `12` |

6. Выберите доступный тариф и нажмите **Deploy Web Service**.
7. Откройте HTTPS-адрес, выданный Render, и проверьте создание сайта.

В проекте есть `render.yaml` для упрощённого создания сервиса. Бесплатный тариф может иметь ограничения или быть недоступен для вашего аккаунта.

### Способ B. GitHub Pages — только интерфейс, отдельно backend

1. В GitHub откройте репозиторий → **Settings → Pages**.
2. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)** → **Save**.
3. Интерфейс будет доступен по адресу `https://aibekmusabek3-del.github.io/liniya-ai/` после публикации.
4. Шаблоны, предпросмотр, код и экспорт работают без сервера.
5. Для генерации с ИИ отдельно запустите backend на Render, затем в конструкторе откройте **Настройки подключения** и укажите HTTPS-адрес Render.
6. Если frontend и backend на разных доменах, добавьте на Render переменную `ALLOWED_ORIGINS=https://aibekmusabek3-del.github.io` и перезапустите сервис. Указывается **origin без `/liniya-ai`**.

GitHub Pages **не запускает Node.js**, поэтому хранить там API-ключ или пытаться отправлять запросы напрямую из браузера нельзя.

## Как пользоваться конструктором

1. На главной странице опишите сайт, нажмите «Создать с ИИ», либо выберите шаблон.
2. В редакторе попросите ИИ изменить сайт, например: «Добавь раздел с отзывами».
3. Переключайте размеры предпросмотра, чтобы проверить мобильную версию.
4. Откройте вкладку **HTML-код**, отредактируйте содержимое и нажмите «Применить изменения».
5. Нажмите **Скачать ZIP**, распакуйте полученный архив и откройте `index.html`.
6. Чтобы опубликовать **созданный сайт**, загрузите его `index.html` в **отдельный репозиторий** и включите GitHub Pages.

## Ограничения и безопасность

- Генерация зависит от доступности OpenAI API, ключа, выбранной модели и баланса API-аккаунта.
- Сайты создаются как самодостаточные HTML-файлы. Настоящие платежи, отправка писем, авторизация и базы данных требуют отдельного backend.
- Сгенерированный код исполняется в iframe с `sandbox="allow-scripts"` без `allow-same-origin`. Перед публикацией проверяйте HTML и JavaScript, поскольку ИИ может ошибаться.
- Проекты хранятся **только в браузере**; очистка данных браузера удалит их. Экспортируйте ZIP для резервной копии.
- Серверные лимиты в оперативной памяти сбрасываются при перезапуске и не являются полной защитой от злоупотреблений. Для публичного проекта нужны настоящая аутентификация, внешние лимиты, защита от ботов и контроль расходов на стороне API-провайдера.
- Не используйте публично ранее опубликованный API-ключ. Его нужно отозвать.

## Технологии

HTML5, CSS3, JavaScript (ES Modules), Node.js HTTP, OpenAI Responses API. Без сторонних npm-зависимостей и без Docker.

## Проверка проекта

```powershell
npm run check
npm test
```

`npm test` проверяет сервер и интеграцию через локальный тестовый ответ вместо платного запроса к OpenAI. Настоящий платный вызов API не выполняется автоматически.
