# ЛИНИЯ — интерфейс генеративной нейросети

«ЛИНИЯ» — адаптивный русскоязычный сайт на HTML, CSS и JavaScript. Дизайн создан в Figma специально для проекта: спокойная светлая палитра, простая навигация, экран начала диалога и экран переписки. **Регистрация не нужна.**

**Figma:** https://www.figma.com/design/k5l6lp804htPe7Xqj5Y5bL

## Что работает

- Новые диалоги, отправка сообщений клавишей Enter или кнопкой, перенос строки через Shift+Enter.
- История диалогов и сообщений в `localStorage` браузера, без регистрации и серверной базы.
- Переключение диалогов, переименование двойным щелчком, удаление одного или всех.
- Карточки быстрых запросов, копирование и повторная генерация последнего ответа.
- Прикрепление **текстового** файла до 100 КБ; из него передаются первые 8000 символов.
- Экспорт истории в JSON.
- Десктопный и мобильный интерфейс, открывающаяся боковая панель, настройки.
- Два режима: демонстрационный без API и реальный ИИ при отдельном запуске Node-сервера.

**Важное различие:** в демо-режиме показываются заранее подготовленные ответы по типу запроса. Это НЕ настоящая генерация нейросетью. Для ИИ необходимо запустить backend и предоставить действительный API-ключ **только на сервере**.

## Как посмотреть сайт (самый простой способ)

Скачайте ZIP, распакуйте папку и откройте `index.html` в браузере. Интернет нужен только для загрузки веб-шрифтов, без него будут стандартные шрифты. Демо-режим работает без установки библиотек.

Также можно использовать расширение VS Code **Live Server**.

## Как разместить на GitHub Pages

1. Создайте публичный репозиторий, например `liniya-ai`.
2. Загрузите содержимое этой папки в **корень** репозитория (`index.html` должен лежать именно в корне).
3. В настройках GitHub откройте **Settings → Pages → Build and deployment → Deploy from a branch**, укажите `main`, папку `/ (root)` и сохраните.
4. Откройте опубликованный адрес. **На GitHub Pages будет работать демо-интерфейс**, история и все локальные функции.

GitHub Pages публикует статические файлы и **не запускает Node.js**. Для настоящих ответов ИИ backend требуется разместить отдельно на сервере, указать его HTTPS-адрес в настройках страницы и настроить CORS.

## Как запустить с настоящим ИИ локально

Требуется Node.js 20+ (в проекте нет npm-зависимостей и `npm install` не нужен).

Откройте терминал в корне проекта. **Не вставляйте секрет в GitHub или `.js` файлы.** Настройте переменную окружения только для текущего PowerShell:

```powershell
$env:OPENAI_API_KEY = Read-Host 'Новый API-ключ OpenAI'
$env:OPENAI_MODEL = 'gpt-4o-mini'
npm start
```

На Linux/macOS:

```bash
read -srp 'Новый API-ключ OpenAI: ' OPENAI_API_KEY; echo
export OPENAI_API_KEY
npm start
```

Откройте http://127.0.0.1:8787. В правом верхнем углу выберите **«ИИ через сервер»**. В настройках поле адреса сервера можно оставить пустым, поскольку сайт и API находятся на одном адресе.

Плата за использование API оплачивается отдельно от ChatGPT. Проверяйте лимиты своего API-аккаунта. **Если ключ когда-либо публиковался в переписке или репозитории, отзовите его и создайте новый.**

### Если фронтенд и backend работают на разных адресах

Укажите на сервере `ALLOWED_ORIGIN` равным точному адресу опубликованного сайта, например `https://username.github.io`, а во всплывающих настройках сайта укажите полный HTTPS-адрес backend. Для работы сайта с HTTPS адрес backend тоже должен быть HTTPS. Разрешайте только свой origin; не открывайте секреты в браузере.

**Предупреждение для публичного API:** пример backend предназначен для локальной демонстрации. Для размещения в интернете потребуется дополнительная защита от злоупотреблений (авторизация по доступу к сервису, лимиты расходов, обратный прокси, мониторинг, фильтрация и надёжное ограничение запросов). Без регистрации у пользователя сайта можно обойтись, но общедоступный backend с оплачиваемым API не стоит публиковать без защиты.

## Структура

```text
index.html           Страницы и интерфейс
styles.css           Дизайн и адаптивная вёрстка
app.js               Диалоги, история, отправка и события UI
favicon.svg          Иконка проекта
server/server.js     Необязательный безопасный локальный шлюз к OpenAI
package.json         Команда запуска локального сервера
.gitignore           Исключение локальных секретов и мусора
```

## Проверка

```powershell
npm run check
npm start
```

Проверяйте: создание диалога; отправку сообщения; повторный ответ; переименование; удаление; обновление страницы (история остаётся); прикрепление текстового файла; экспорт; отображение на экране телефона; ответы API при подключённом сервере.

## Ограничения

Данные находятся в браузере на текущем устройстве, не синхронизируются между устройствами. Демо-режим не предоставляет генерацию изображений и не анализирует файлы нейросетью. Для публикации реального сервиса требуется отдельно развернуть backend с защитой ключа и расходов. Не храните пароли, банковские данные и другие секреты в локальной истории.
